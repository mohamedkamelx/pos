      Power & connections
      For a dedicated counter, keep the computer plugged in and prevent sleep or hibernate while serving. Battery settings affect battery life. Posnic does not change these Windows settings.
      If USB disconnects, inspect the affected USB hub in Device Manager → Properties → Power Management. Temporarily test without “Allow the computer to turn off this device to save power”, where available. Restore it if there is no improvement.
      For extender connections, test with a short direct USB cable across the usual idle period. Initialization cannot restore a device Windows cannot see.
      
                    
      About idle initialization
      ESC @ resets printer state; it is not a guaranteed wake command. Enable only for compatible ESC/POS printers. It pauses during app printing or disconnection. Do not run a separate keep-alive helper alongside it.
      Checks refresh while this page is open. System results may be cached for one minute. Windows recovery controls are available on Windows only.

                        Scale connection and reading format
                        
      For serial connections, match these values to the scale's manual. Readings are converted to kilograms.
      
                        
      
                            
                            
                            
                            
                            
                            
                            
                            
                            
                            
                            
                            
                            
                        
      
                        
      Units sent by the scale always take priority. For 00375 meaning 0.375 kg, choose Kilograms and 3 implied decimal places. If a message contains several numbers, choose its weight number (1 = first). For fixed-width streams without line endings, enter the frame length from the manual.
      
                        
      Scale requires a read command
                            
                            
                        
      
                        
      Connect, place a known weight and verify the live value below. Choose a protocol documented by your scale manufacturer. Proprietary binary, USB HID and OPOS devices need their matching driver; do not select a text preset for them.

      If a scan does not work
      
                    
        
                        
      • Nothing appears at all - the scanner is not in keyboard
                            mode. Most scanners ship with a manual containing a "USB HID" or
                            "keyboard wedge" barcode; scan that one.
        • 
                        
      • Digits appear but the item is not found - the barcode is
                            not on any item yet. Add it in the item's Barcode field.
        • 
                        
      • The code appears but nothing happens until you press Enter
                            - the scanner is not sending a return. Its manual has a "add Enter
                            suffix" barcode.
        • 
                        
      • Letters or symbols instead of digits - the scanner is set
                            to a different keyboard layout than this computer. Set both to the same.
